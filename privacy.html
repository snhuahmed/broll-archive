Privacy policy

Last updated: October 5, 2026

Broll archive is a personal tool used only by its owner to upload the owner's own video-editing project files to the owner's own Google Drive.

What data it accesses

Using Google's drive.file permission, it can only create, read and update files that it uploaded itself. It cannot see or change any other files in Google Drive.

What it collects and shares

It collects no personal data, uses no analytics or tracking, and shares no data with anyone. Files go directly from the owner's computer to the owner's Google Drive. The access token is stored only on the owner's own computer.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/permissions.
